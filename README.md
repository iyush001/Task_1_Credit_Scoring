# Credit Scoring Model

This project predicts credit risk using customer financial information.

## Objective

The objective is to classify customers based on their credit risk using machine learning.

## Dataset

German Credit dataset.

## Algorithms Used

- Logistic Regression
- Random Forest

## Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Result

The trained models are compared based on their classification performance.

## How to Run

The project is provided as a Jupyter Notebook. It can be opened and executed using Google Colab or Jupyter Notebook.
